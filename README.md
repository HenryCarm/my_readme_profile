# my_readme_profile 💾

Self-hosted assets for [HenryCarm](https://github.com/HenryCarm)'s profile README.

Every wave, typing SVG, badge, skill icon, stats card, and snake lives here so the profile never goes ugly if external services die.

## Layout

```
assets/
  header.svg / footer.svg   — capsule-render waves
  typing.svg                — terminal typewriter
  stats.svg / streak.svg / top-langs.svg / activity-graph.svg
  snake.svg / snake-dark.svg — contribution snake (Action → output branch)
  views.svg                 — profile view counter snapshot
  icons/                    — skillicons.dev 128×128 tech icons
  badges/                   — shields.io chips
```

## Refresh stats

The static SVGs are snapshots. Re-run the download script or hit the original services and replace the files to refresh.
